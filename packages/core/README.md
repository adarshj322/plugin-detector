# @plugin-detector/core

Core schemas, taxonomy, scoring, verdicts, and install safety primitives for
[plugin-detector](https://github.com/adarshj322/plugin-detector), a local-first
harness plugin recommender.

This package is a library dependency of the `plugin-detector` CLI. Install the
CLI with `npm install --global plugin-detector`.
