# @plugin-detector/cursor

Cursor detection and inventory adapter with recipe-only installs for
[plugin-detector](https://github.com/adarshj322/plugin-detector).

Cursor mutation is intentionally recipe-only in v0.1, and MCP is the documented
path while skills/rules/commands remain experimental. This package is a library
dependency of the `plugin-detector` CLI. Install the CLI with
`npm install --global plugin-detector`.
