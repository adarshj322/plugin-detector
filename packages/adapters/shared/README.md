# @plugin-detector/adapter-shared

Shared parsing and file-safety helpers for plugin-detector harness adapters.

Part of [plugin-detector](https://github.com/adarshj322/plugin-detector), a
local-first harness plugin recommender. This package is a library dependency of
the `plugin-detector` CLI. Install the CLI with
`npm install --global plugin-detector`.
