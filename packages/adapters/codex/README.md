# @plugin-detector/codex

Codex detection and inventory adapter with recipe-only installs for
[plugin-detector](https://github.com/adarshj322/plugin-detector).

Codex mutation is intentionally recipe-only in v0.1: the adapter never writes
Codex config. This package is a library dependency of the `plugin-detector` CLI.
Install the CLI with `npm install --global plugin-detector`.
