# @plugin-detector/opencode

OpenCode detection, inventory, compatibility, and verified-only install adapter
for [plugin-detector](https://github.com/adarshj322/plugin-detector).

This package is a library dependency of the `plugin-detector` CLI. Install the
CLI with `npm install --global plugin-detector`. See the adapter documentation
at <https://github.com/adarshj322/plugin-detector/blob/main/docs/adapters.md>.
