# @plugin-detector/registry

Registry snapshot loader, source refresh, normalization, and trust
classification for [plugin-detector](https://github.com/adarshj322/plugin-detector).

The package ships the bundled registry snapshot under `data/`. This package is a
library dependency of the `plugin-detector` CLI. Install the CLI with
`npm install --global plugin-detector`.
