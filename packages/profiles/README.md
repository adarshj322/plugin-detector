# @plugin-detector/profiles

Bundled use-case profiles and resolver for
[plugin-detector](https://github.com/adarshj322/plugin-detector).

Profiles map a declared use case to canonical capability domains and
corroborating project signals. See the profile schema at
<https://github.com/adarshj322/plugin-detector/blob/main/docs/profile-schema.md>.

This package is a library dependency of the `plugin-detector` CLI. Install the
CLI with `npm install --global plugin-detector`.
